# اطلاع‌رسانی تلگرامی (Telegram Admin Alerts)

همه‌ی رویدادهای مهم سایت به‌صورت فوری به تلگرام ادمین اطلاع داده می‌شوند.
این سیستم **fire-and-forget** است: اگر تلگرام پایین باشد یا توکن تنظیم
نشده باشد، هیچ‌گاهی بازدیدکننده یا ثبت‌نام تحت تأثیر قرار نمی‌گیرد.

---

## ۱. رویدادهای اطلاع‌داده‌شده

| رویداد | زمان ارسال |
|---|---|
| 👤 عضویت کاربر جدید | به‌محض ثبت‌نام (ایمیل/پسورد و Google OAuth) |
| 📦 محصول جدید | به‌محض ایجاد محصول (وضعیت «در انتظار تأیید») |
| 📋 درخواست خرید جدید | به‌محض ایجاد درخواست (وضعیت «در انتظار تأیید») |
| 👁️ بازدید محصول / درخواست / پروفایل | به‌محض هر بازدید — **شامل کشور بازدیدکننده** |

نمونه‌ی پیام بازدید:

```
👁️ بازدید محصول
عنوان: Basmati Rice 1121
کشور بازدیدکننده: Iran (IR)
تعداد کل بازدید: ۴۲
زمان: 2026/10/09, 14:32:05
مشاهده صفحه ← (لینک)
```

---

## ۲. راه‌اندازی (۵ دقیقه)

### ۲.۱ ساخت ربات

1. در تلگرام با [@BotFather](https://t.me/BotFather) چت کنید
2. دستور `/newbot` بدهید و اسم ربات را انتخاب کنید
3. توکن (`123456:ABC-...`) را کپی کنید

### ۲.۲ پیدا کردن آیدی چت

ساده‌ترین راه: در تلگرام با [@userinfobot](https://t.me/userinfobot) چت
کنید — آیدی عددی خودتان (مثلاً `987654321`) را نشان می‌دهد.

> برای گروه: ربات را به گروه اضافه کنید و آیدی گروه را با
> `https://api.telegram.org/bot<TOKEN>/getUpdates` بگیرید
> (آیدی گروه‌ها با `-100` شروع می‌شود).

### ۲.۳ تنظیم .env

```bash
TELEGRAM_BOT_TOKEN="123456:ABC-DEF..."
TELEGRAM_CHAT_ID="987654321"
# اختیاری:
TELEGRAM_MAX_PER_MINUTE="30"   # سقف پیام در دقیقه (پیش‌فرض 30)
```

**چند چت:** آیدی‌ها را با کاما جدا کنید:
`TELEGRAM_CHAT_ID="987654321,-1001234567890"`

### ۲.۴ اجرای migration (فقط بازدید پروفایل)

برای شمارش بازدید پروفایل، ستون `views` به جدول `User` اضافه شده:

```bash
npx prisma generate
npx prisma db push
```

> ⚠️ بدون این دو دستور، بازدید پروفایل خطای «ستون وجود ندارد» می‌دهد.
> بازدید محصول و درخواست نیاز به migration ندارند (ستون از قبل وجود دارد).

## ۳. معماری

```
src/lib/telegramService.js   ارسال پیام (نرخ‌محدودیت، چند چت، HTML)
src/lib/geoIp.js             تشخیص کشور بازدیدکننده
src/lib/adminAlerts.js       قالب‌های اطلاع (کجا چه پیامی بفرستد)
```

**نقاط اتصال:**

| محل | رویداد |
|---|---|
| `src/app/api/auth/register` | `dispatchEvent("user.registered")` → `alertNewUser` |
| `src/auth.ts` (OAuth) | `createUser` → `alertNewUser` |
| `src/app/api/products` (POST) | → `alertNewProduct` |
| `src/app/api/requests` (POST) | → `alertNewBuyingRequest` |
| `src/app/api/track-view` | بازدید + `getViewerCountry` → `alertNewView` |

**نکات طراحی:**

- اطلاع بازدید داخل `after()` اجرا می‌شود تا پاسخ API فوری برگردد
  (lookup کشور تا ۴ ثانیه طول می‌کشد).
- یک سقف پیام در دقیقه (`TELEGRAM_MAX_PER_MINUTE`) از flood شدن
  API تلگرام جلوگیری می‌کند.
- کش IP→کشور ۶ ساعته در حافظه، تعداد درخواست‌های خارجی را کم می‌کند.

---

## ۴. کشور بازدیدکننده چطور تشخیص داده می‌شود؟

۱. اول هدرهای پلتفرم خوانده می‌شوند:
   `x-vercel-ip-country` (Vercel)، `cf-ipcountry` (Cloudflare)،
   `x-country-code`، `x-geo-country`.
2. اگر نبودند، IP کلاینت (از `x-forwarded-for` یا `x-real-ip`) با
   [ipapi.co](https://ipapi.co) چک می‌شود.

**برای سرور خودتان (Nginx):** این هدر را به بلاک `location` اضافه کنید
تا lookup خارجی لازم نباشد (سریع‌تر و بدون محدودیت درخواست):

```nginx
# با ماژول geoip2 (MaxMind) در Nginx:
proxy_set_header X-Country-Code $geoip2_data_country_code;
```

**در توسعه (localhost):** IP خصوصی است و کشور «نامشخص» نشان داده می‌شود —
این طبیعی است.

## ۵. خاموش کردن

| هدف | تنظیم در .env |
|---|---|
| همه‌ی اطلاع‌ها | `TELEGRAM_ALERTS_ENABLED="false"` |
| فقط بازدیدها (پرحجم‌ترین) | `TELEGRAM_VIEW_ALERTS="false"` |
| فقط عضویت‌ها | `TELEGRAM_USER_ALERTS="false"` |
| فقط محصولات | `TELEGRAM_PRODUCT_ALERTS="false"` |
| فقط درخواست‌ها | `TELEGRAM_REQUEST_ALERTS="false"` |

> ⚠️ بازدیدها حجم بالایی دارند. اگر ترافیک سایت زیاد شد،
> `TELEGRAM_VIEW_ALERTS` را خاموش کنید و از خلاصه‌ی روزانه
> (بخش ۶) استفاده کنید.

---

## ۶. گام بعدی (پیشنهاد)

- **خلاصه‌ی روزانه:** یک `ScheduledJob` که هر روز آمار بازدید/عضویت را
  به‌صورت یک پیام واحد بفرستد (از `src/lib/jobHandlers.js`).
- **GeoIP محلی:** با MaxMind GeoLite2 (`@maxmind/geoip2-node`) بدون
  درخواست خارجی و بدون محدودیت ipapi.co.
- **رویدادهای بیشتر:** ایجاد تیکت، پرداخت، نظر محصول — کافی است
  `alertXxx` جدیدی در `adminAlerts.js` بسازید و از نقطه‌ی وقوع صدا بزنید.
